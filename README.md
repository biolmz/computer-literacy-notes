# 计算机教程

一套一套的中文动手讲义，一个主题一个目录。

共同的写法：**每讲一个概念，立刻用一个能跑起来的小实验验证它**。每份分册都能单独打印成一张实验单，自带目标、步骤、预期输出、验证清单和排错表——打印出来就能照着做，不用在几十页里找“我现在在第几步”。

> 仓库按主题持续增补。下表只列已经写完的，新的一套直接加在末尾。

## 怎么用

**挑一套开始。** 各套互不依赖，目录名就是主题名，点进对应目录的 README 看逐册说明。

**一套内部按编号顺序做**，不要跳——每个实验都复用上一个的成果，跳着做会在中途卡住。想直接解决眼前问题的话，各套 README 里都写了“哪个实验对应哪个症状”的直达索引。

**如果完全没有基础**，当前建议的顺序是先版本控制、后环境隔离：

| 阶段 | 对应讲义 | 做什么 | 用时 |
| :--: | :--- | :--- | :--: |
| 1 | Git 00 + 01~04 | 装好 Git，走完 建仓库 → 暂存 → 提交 → 看历史 → 撤销 → 分支合并。本地操作的全部基本功。 | 约 1.5 h |
| 2 | Git 05~08 | 冲突、本机模拟远程、真实推 GitHub、`reflog` 救援。建议另找一天做。 | 约 2 h |
| 3 | Docker 主册第 1~4 章 | 镜像、容器、仓库、分层四个概念，先建立地图再动手。 | 约 30 min |
| 4 | Docker 01~06 | 从跑起一个网页到把 pandas + matplotlib 装进镜像。 | 约 2.5 h |

新主题接在末尾，这条路线只往后加、不改前面的序号。

## 环境要求

各套需要什么，看下表；每套 README 里还有更细的说明。

| 工具 | 版本 | 说明 |
| :--- | :--- | :--- |
| Git | ≥ 2.23 | 这个版本之后才有 `git switch` / `git restore`，Git 讲义全程用新命令 |
| Docker | 27 / Compose v2 | 老教程里的 `docker-compose`（带横线）是 v1，已停止维护 |
| Node.js | 18+ | 只在需要从源码重建 PDF 时用，做实验不需要 |
| PDF 阅读器 | 任意 | A4 单面打印，正文没有跨页的大表格 |

**Windows 用户注意两个 shell 的分工**：敲讲义里的 git 命令用 Git Bash（装 Git 时自带），别用 cmd 或 PowerShell——两者对引号、路径、`Ctrl+C` 的处理都不一样，输出会对不上；还原脚本 `setup.ps1` 反过来要用 PowerShell 跑。Docker 讲义里涉及 `D:/` 路径挂载的命令，同样建议用 PowerShell。

**离线可用**：除 Git 实验 07（推 GitHub）和 Docker 拉镜像之外，其余实验只依赖本机。

## 关于这些 PDF

仓库里的讲义都是同一套做法生成的，改内容不用碰排版：

- **排版**：单文件 HTML + 一份共享 CSS，用 Chrome 打印成 A4，页脚带页码；每章另起一页，代码块和表格尽量不跨页。
- **图示**：全部是内联 SVG（对比图、分层图、端口映射、状态机、挂载关系、Compose 架构），没有外部图片，放大不失真。
- **可搜索**：正文是文本而不是扫描件，`Ctrl+F` 能直接查到某条命令。
- **字体**：优先用系统自带字体（微软雅黑 / 苹方），代码用 Consolas / Cascadia Mono；个别讲义为了打印一致性会嵌入字体。

## 边界

每套讲义都在自己 README 里写清了不覆盖什么——不是那些内容不重要，而是没碰到真实场景时学了也记不住。当前已知的排除范围：

- **Git**：`rebase` / `cherry-pick` / PR 评审流程 / `tag` 发版 / `bisect` / Git LFS / 子模块。
- **Docker**：Swarm、Kubernetes、容器网络进阶、镜像安全扫描。

## 新增一套讲义时

保持结构一致，以后加主题只要照这个清单走一遍：

1. **新建目录**，目录名就是主题名，中文直接写（如 `Shell入门实验讲义/`）。
2. **目录内必须有 `README.md`**，至少包含：逐册清单表（编号 / 页数 / 讲什么 / 做完你会得到）、总用时、前置要求、不覆盖的边界、许可说明。
3. **PDF 命名**：主册 `主题 入门教程.pdf`，分册 `实验0X_主题.pdf`，编号两位数字——保证 `实验01` 一定排在 `实验10` 前面。
4. **配 `.gitignore`**：根目录那份已经覆盖了系统垃圾、编辑器目录、`node_modules/`、`out_*.pdf` 这类通用项，**通常不用动**；只有新主题有专属产物（比如别的导出命名）时，才在它自己目录里补一份。
5. **需要起始文件的实验**，放 `实验文件/0X_主题/`，四件套：`setup.ps1` + `setup.sh` + `files/` + `README.txt`。起始文件统一 UTF-8 无 BOM + LF，用 `.gitattributes` 兜住，否则 `git diff` 的输出会和讲义对不上。
6. **回到本文件**：在「讲义目录」表末尾加一行，在「目录结构」里补一段。

不用动的部分：学习路线表往后加阶段即可，环境要求表按需加行。

## 发现错误怎么办

讲义里的每一条命令、每一段输出都在本机跑过并核对过。但如果你照着敲却对不上，那大概率是写错了，而不是你做错了——欢迎提 issue，注明是哪一套、哪一册、第几步，以及你的完整输出。

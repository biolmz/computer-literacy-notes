06_本机模拟远程  ·  本机模拟远程：push、pull 与一次被拒
================================================================

讲义 PDF 不在本文件夹里，它在“实验文件”的上一层（整套讲义根目录），文件名：
  实验06_本机模拟远程.pdf

本文件夹里有：

  setup.ps1         Windows 一键还原起始状态
  setup.sh          macOS / Linux 一键还原起始状态
  files/            起始文件原件
                    （本实验不需要起始文件，这个目录是空的）
  README.txt        就是本文件

----------------------------------------------------------------
怎么用
----------------------------------------------------------------

Windows：
  1. 在资源管理器里按住 Shift 右键空白处 → “在此处打开 PowerShell 窗口”
  2. 执行：  powershell -ExecutionPolicy Bypass -File setup.ps1
  3. 脚本会建好 %USERPROFILE%\git-lab\lab06 并写入起始文件

macOS / Linux：
  bash setup.sh

做完一遍想从头再做：
  setup.ps1 -Force      （Windows）
  bash setup.sh --force （macOS / Linux）

注意：-Force / --force 不会删除任何东西，它只是把旧目录改名成
      lab06_bak_日期时间 留在原地。确认不要了再自己删。

----------------------------------------------------------------
为什么要用脚本而不是手动复制粘贴
----------------------------------------------------------------

因为本讲义里的每一步都假设起始文件是“一字不差”的样子。
手动复制时最常见的三个坑：多了空行、换行符变成 CRLF、文件被存成
UTF-8 带 BOM。任何一个都会让 git diff 的输出和讲义对不上，
然后你就得花半小时怀疑是不是自己做错了。

脚本写的是 UTF-8 无 BOM、LF 换行，和讲义里的输出完全一致。
